# 淘宝双11 淘金币活动自动化（2026）

用 [uiautomator2](https://github.com/openatx/uiautomator2) 驱动安卓手机，自动完成淘宝
「淘金币双11狂享20亿」活动页里的能量任务、累计奖励，并把能量拿去「升级赛车拿钱」换成抵金。

这个仓库目前只有 `2026淘宝双11.py` 一个脚本，不依赖任何其它项目文件。
以后要加别的活动脚本（618、芭芭农场、闲鱼等），直接放在根目录即可。

## 前置条件

1. 电脑装了 adb（Google platform-tools），并且能在命令行里执行 `adb devices`
2. 手机开启「开发者选项 → USB 调试」，数据线连电脑后 `adb devices` 能看到设备
3. 淘宝已登录（脚本会自己拉起淘宝，不会动登录态）
4. Python 3.10+，装依赖：

```bash
pip install -r requirements.txt
```

## 用法

```bash
# 默认：做能量任务 + 升级赛车
python 2026淘宝双11.py

# 只做 5 个任务，调试用
python 2026淘宝双11.py --max-tasks 5

# 不做赛车，只做任务
python 2026淘宝双11.py --skip-race

# 只把剩余能量换成抵金
python 2026淘宝双11.py --race-only

# 只打开活动页，不点任务
python 2026淘宝双11.py --open-only

# 多台设备时指定序列号
python 2026淘宝双11.py --serial 3B1F4QE5MS14AFS6
```

## 它会做什么

- 进活动页先关掉音效（右上角喇叭 + 任务面板里的独立开关）
- 做浏览类任务，按任务要求的次数做到满（3 次 / 5 次 / 10 次都一样）
- 做本机已装 App 的跳转任务：允许跳转 → 在对方 App 里逛够时间 → 重启淘宝回活动页 → 核对计数
- 领累计任务奖励（20 次 / 50 次那几格）
- 把能量长按换成抵金（赛车升级）

## 它不做什么

- 拉人 / 邀请 / 助力类任务
- 天猫积分换能量（按钮是「去兑换」）
- 小游戏任务
- 要下单、充值、开卡的任务
- 目标 App 手机里没装的跳转任务（日志会写 `手机没装 X`，不会去下载）

这些规则在脚本开头的 `SKIP_KEYWORDS` 里，可以自己改。

## 已知问题

- 活动页是 WebView，无障碍树偶尔会整片取不到（页面看着正常，取到的节点却只有几十个）。
  脚本会自动「关面板重开 → 重启淘宝 → 重新进活动页」，日志里能看到 `重启淘宝（第 N 次）`。
- 跨 App 任务会点系统确认框的「30天内允许」，即给淘宝 30 天跨应用跳转授权。
  不想给就把 `JUMP_ALLOW_LABELS` 里的「30天内允许」删掉，只留「仅本次允许」。
- 活动页改版会导致选择器失效：这个脚本是按 2026 年 10 月的页面结构写的，
  文案/按钮变了就要跟着改 `PANEL_TITLE`、`RACE_TXT`、`find_nodes` 里的关键字。
- 跑的时候尽量别动手机，脚本靠点屏幕和返回键推进。
